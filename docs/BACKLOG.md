## Гүйцэтгэл (Lighthouse mobile ≥ 80 зорилт хангагдаагүй)

- JS-ийг нэгтгэж minify хийх build алхам (одоо 40 тусдаа файл).
- Firebase compat SDK-ийг modular, tree-shaken хувилбараар солих (~300 KB-ийг хасна).
- Firebase Auth-ийн gapi iframe-ийг зөвхөн нэвтрэх үед ачаалах.
- index.html-ийн нуугдсан хэсгүүдийг тусдаа template болгож хуваах.
- Demo зарын зургуудыг WebP/AVIF болгох.

## Accessibility

- Beta мөр болон "Баталгаажсан" тэмдгийн өнгөний contrast.
- Гарчгийн дараалал (h4 нь h2/h3-гүйгээр орсон).

## Өгөгдөл

- Бодит зар болон хэлцлийн эх сурвалж: өөрийн зар оруулагчид, түнш агентууд, гэрээт эх сурвалж. Өөр сайтаас зөвшөөрөлгүй татахгүй.
- Зарын шалгуурын (leave-one-out) тооцоо: тухайн зарыг өөрийн хотхоны дунджаас хасаж харьцуулах.
